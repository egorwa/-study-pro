# Study Pro

Study Pro is a Blazor web application that helps college students organize personal assignments, due dates, priorities, and progress.

## Technology

- .NET 8
- ASP.NET Core
- Blazor Web App
- Interactive Server rendering

## Project Structure

```text
StudyPro.sln
src/
  StudyPro/
    StudyPro.csproj
```

## Run Locally

From the repository root, run:

```powershell
dotnet restore
dotnet build
dotnet run --project src/StudyPro/StudyPro.csproj
```

Open the HTTPS or HTTP address displayed in the terminal.

## Development Workflow

1. Pull the latest changes from `main`.
2. Create a branch for the assigned Trello card.
3. Build and test the changes locally.
4. Push the branch and open a pull request.
5. Ask another team member to review the pull request before merging.
